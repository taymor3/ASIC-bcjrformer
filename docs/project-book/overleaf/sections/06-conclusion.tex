\section{Conclusions}
BCJRFormer was studied as a digital inner-decoding workload, implemented as a five-stage SystemVerilog core, and evaluated through two separate experiments. The architecture makes the boundary explicit: the host loads trained parameters and prepared inputs, while the core returns indexed logits using shared compute and a memory-backed schedule. Ready/valid transactions and committed-write barriers coordinate data and control. The fixed-point description identifies where precision, approximations, and rounding affect the computation.

One trained-model frame matched all 144 fixed-point reference words. The dated fixtures add evidence for arithmetic, internal writes, and selected controller behavior. The small-core synthesis exercise demonstrated library mapping and exposed a LayerNorm setup limitation at the 20\,ns target. The logged 200\,ns result met its synthesis constraint with a narrow setup margin. The two results establish different milestones and provide a basis for further lab work.

\subsection*{Next verification steps}
Extend trained-model evaluation across additional read counts and padding cases. Connect future RTL and physical runs to source and parameter configurations, and obtain verified timing and power evidence for a named implementation. Physical memory mapping is a separate integration step. A broader decoding evaluation should report target-bit performance and integer-to-RTL agreement separately.
