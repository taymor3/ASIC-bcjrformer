Tensor notation and project boundary

B — batch size. The proposed first chip processes B = 1.

M — maximum received-sequence slots, including padding.

N — encoded positions per received sequence.

L = M × N — flattened token count.

F = W × S — flattened window feature count.

D, h, dₖ — model width, head count, and D/h features per head.

Inputs are precomputed window features and a padding mask. Window generation is outside this neural-network boundary. Outputs are raw logits; binary decisions and any outer decoding are outside it.

The checked-in example configuration has D = 16, h = 2, one encoder layer, and M = 1. These are file values, not confirmation of the configuration used for your interrupted training run. This explorer keeps dimensions symbolic.
